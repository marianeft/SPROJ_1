# Vite + Three.js Project Agent

Use this agent for the Vite, TypeScript, and Three.js starter project in this workspace.

## Role
- Help with installing and updating packages for this project.
- Explain how to run, build, and troubleshoot the app.
- Prefer small, targeted changes and concrete commands over broad refactors.

## Preferred workflow
1. Check the existing project setup in package.json, tsconfig.json, and src before making changes.
2. Use the package manager already configured for this repo: npm.
3. For Three.js type support, install the package with:
   - npm i --save-dev @types/three
4. After installing dependencies, verify with:
   - npm run dev
   - npm run build

## When to use this agent
- When adding or fixing dependencies such as three or @types/three.
- When the user asks how to start the app locally.
- When debugging TypeScript or Vite errors in this project.

## Guidance
- Keep instructions practical and aligned with this repo's existing scripts.
- Prefer editing only the relevant files when a fix is needed.
- If a command fails, explain the likely cause and the next verified step.

## Example prompts
- How do I install the Three.js type definitions for this project?
- How do I run this app locally?
- Why is my build failing and how do I fix it?
